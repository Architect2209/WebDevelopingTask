# WebDevelopingTask
LOL INSIGHT — вебплатформа статистики, білдів та рун League of Legends

# Проблема, мета та цільова аудиторія
Гравцям League of Legends складно знайти в одному місці достовірну статистику чемпіонів, оптимальні білди та руни, а також зручний інструмент для аналізу власного профілю. Мета — зручна платформа для перегляду статистики чемпіонів, побудови білдів і аналізу історії ігор. Цільова аудиторія: гравці League of Legends різного рівня — від новачків до рейтингових гравців.

# Основні функції та сторінки
Каталог чемпіонів з пошуком і фільтрами, детальна сторінка статистики чемпіона (руни, білди, вінрейт, контр-піки), конструктор білдів, профіль користувача з історією ігор, лідерборд з фільтрами, аналіз ігор про-гравців, розміщення реклами.
